# Prompt Collector (AI 提示詞展示與收藏庫)

本專案收錄高品質 AI 圖像生成（Midjourney v6.1 / Flux.1 [dev] / Stable Diffusion）設計海報二創、建築藍圖線稿與電影感攝影之結構化提示詞。

所有提示詞均統一遵循 **五模組標準英文架構 (5-Part Modular Schema)**：
1. `[FORMAT & RATIO]`：畫幅比例與版面切割規範。
2. `[TOP HALF — PHOTO REALISM]`：原片真實感、透視與光影保留。
3. `[BOTTOM HALF — RECONSTRUCTED MEDIUM]`：藝術媒材重構（紙雕微縮、極簡手繪、手撕紙拼貼等）。
4. `[EDITORIAL TYPOGRAPHY]`：現代編輯字體、標題與元數據排版系統。
5. `[NEGATIVE PROMPT & PARAMS]`：排除項與推薦生成參數。

## 網頁展示庫 (Web Showcase)
本專案為零外部依賴單檔架構，直接使用瀏覽器開啟 `prompt-showcase.html` 即可瀏覽：
* 3:4 作品牆：首頁只顯示成果圖、標題與大分類，卡片右上角可一鍵複製提示詞
* 五大分類篩選（依 `category` 欄位：紙藝立體 / 手繪插畫 / 拼貼混媒 / 建築線稿 / 電影攝影）
* 詳情面板：點卡片開啟，左圖右文；提示詞依五模組拆成彩色可折疊區塊，可單獨複製每個模組
* `提示詞` / `中文解析` / `JSON` 三分頁切換，鍵盤 ← → 切換上下一則，Esc 關閉
* 支援網址錨點直接開啟單一案例（例如 `prompt-showcase.html#case-03`）
* 全螢幕高清 Lightbox 燈箱預覽

> 新增案例時，請在 `showcaseData` 與 `prompts.json` 中填入 `category`；沒有 `image` 的案例會自動排到最後並標示「概念預覽」。
